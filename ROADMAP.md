# Roadmap

Pramaan is built offline-first for India. Planned work, in rough order:

- **v1.1** — Expand the scam-template library with more regional-language variants (Tamil, Telugu, Bengali).
- **v1.2** — Add a "report to 1930" helper that pre-fills the complaint form from a saved scan.
- **v1.3** — Optional on-device QR image scanning (camera) in addition to pasted payloads.
- **v2.0** — Desktop (Windows/macOS) build of the same engine.

Contributions that add a new template with a test proving it scores at least `dangerous` are the most valuable. See [CONTRIBUTING.md](CONTRIBUTING.md).
